SCENARIO 1 — Dijkstra: Router 1 → Router 8
Expected: Cheapest path by link weight.
Steps:
  Menu 6 → Select 1 (Dijkstra)
  Menu 5 → Source: 1, Destination: 8
Expected path: Alpha[1] → Charlie[3] → Delta... actually:
  1→2→3 cost 5, then 3→5 cost 8 then 5→7 cost 3, 7→8 cost 4 = total 20
  OR 1→3→5 cost 10, 5→7 cost 3, 7→8 cost 4 = total 17
  Dijkstra result: 1→3→(4 via 1-2-3 or direct?) - let the simulator decide.
  Correct Dijkstra answer: Alpha → Charlie → Echo → Golf → Hotel, cost = 17
  BFS answer (fewest hops): 3 hops: Alpha → Charlie → Echo → Hotel
  (BFS finds 1→3→5→8 in 3 hops, cost=20 via weights, vs Dijkstra's 4 hops cost 17)
  → DIFFERENT results: demonstrates why algorithm choice matters!

SCENARIO 2 — BFS: Router 1 → Router 8
Expected: Fewest hops path.
Steps:
  Menu 6 → Select 2 (BFS)
  Menu 5 → Source: 1, Destination: 8
Expected: 3 hops → Alpha → Charlie → Echo → Hotel (cost 20 by weight, but fewer hops)

SCENARIO 3 — Packet Transmission

  Menu 6 → Select 1 (Dijkstra)

SCENARIO 4 — Link Failure with Rerouting
(Assumes Packet was just sent from 1→8 using the Dijkstra path above)
Steps:
  Menu 8 → Source: 5, Destination: 7  (remove link Echo-Golf from route)
Expected:
  - LINK FAILURE DETECTED
  - Previous route displayed
  - New route computed (alternative around the failure)
  - reroutedPackets++ in statistics
